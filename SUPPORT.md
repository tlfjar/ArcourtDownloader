# Software support

ArcourtDownloader is an unofficial utility with no affiliation with or endorsement
by the Arkansas Judiciary or Administrative Office of the Courts (AOC). Support
is limited to this software's setup, preview, selection, download, and local file
behavior. It does not cover legal advice, case status, filing, service, deadlines,
official notices, court-site accounts, or access to sealed/unpublished records.
Use the appropriate court's official channels for those matters.

Read the [README](README.md), [CLI guide](docs/command-line-workflow.md), and
[desktop guide](docs/desktop-architecture.md) first. Report software bugs or
request features using the
[public issue forms](https://github.com/tlfjar/ArcourtDownloader/issues/new/choose)
when the planned public repository is available. Include version/build or source
revision, Windows version and architecture, browser and WebView2 versions when
relevant, and synthetic steps to reproduce. Support is best-effort with no
guaranteed response time.

Public issues must exclude court PDFs, client documents, credentials, signed
URLs, browser profiles, and unredacted client screenshots. Do not attach raw
manifests, settings, preview output, logs, or live case captures. Replace case
identifiers, names, paths, and document content with fabricated examples before
sharing text. Screenshots are unnecessary; describe the behavior using synthetic
data. Keep real downloads and diagnostic records on your own machine.

Report suspected vulnerabilities through the [private security process](SECURITY.md).
